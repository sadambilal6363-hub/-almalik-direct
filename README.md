# من المالك مباشرة
منصة عقارات ومساحات مباشرة بين المالك والباحث عن عقار.

## الفئات
1. صناعية
2. محلات تجارية
3. مكاتب
4. مستودعات
5. سكني
6. حوطات
7. متاجر
8. أراضٍ خالية

## المزايا الحالية
- عقارات من المالك مباشرة
- شارة "مالك مباشر"
- نموذج إضافة عقار
- مراجعة قبل النشر
- بحث وفئات
- واتساب مباشر
- Mobile-first
- Next.js
